# Visuels des viseurs pros

Relevés le 13/10/2026 sur les pages publiques `https://crosshair.club/players/{slug}`.
Slugs : donk, s1mple, m0nesy, niko, zywoo, xantares, ropz, b1t, twistzz, jl.

Chaque PNG est l'image du canvas de viseur rendu par la source pour le code affiché à côté, au zoom 1×, 132×132 pixels. Ni image générée par IA, ni aperçu calculé avec la géométrie approximative de LaFineEquipe. Ce n'est pas une capture du moteur CS2 ; taille et rendu en jeu dépendent des paramètres du joueur.

Le nom du fichier contient un hash SHA-256 tronqué du code correspondant. `src/lib/pro-crosshairs.json` conserve code, image, page source, date de relevé et observation indiquée par la source. L'interface affiche cette image uniquement pour ce code exact et à un agrandissement entier ×2, sans interpolation.

La référence de présentation fournie par le propriétaire est https://prosettings.net/tools/cs2-crosshair-database/ . Aucun portrait, fond de map, habillage de carte ou script de ces sites n'est repris. La paire code/visuel de crosshair.club a été retenue pour éviter de mélanger des versions différentes entre fournisseurs. Aucun accord de partenariat ou licence ouverte n'est revendiqué.
